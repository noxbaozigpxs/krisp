## 🤖 Overview

Krisp uses deep neural networks to filter microphone and speaker noise in real time, ensuring crystal-clear audio on any conferencing platform with zero configuration.

Whether you're a newcomer or a veteran, Krisp provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.
